## 📱 Responsive Design Details

The website supports all major device sizes:
- **Small phones (≤480px)** — Single-column layout, hidden secondary images  
- **Tablets (481px–1023px)** — Two-column layout, optimized skill grid  
- **Laptops (1024px–1279px)** — 4–5 column grids and fluid spacing  
- **Large Desktops (≥1280px)** — Full-width balanced sections  

All layout responsiveness is managed through a dedicated file:  
> `media-queries.css`
